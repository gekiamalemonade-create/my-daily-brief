# 事実の扱い（最重要）
- 数字・日付・固有名詞・出来事は、下の「素材」に書かれているものだけを使う。素材にないことは言わない。
- 各行の sources に、その行に含まれる事実の出典ID（S1 など）を入れる。事実を含まない行は空の配列。
- ニュースは話の中で出典を言う（例:「NHKによると」「農林水産省の発表では」）。
- 事実・見解・予測をはっきり分ける。予測や意見は誰のものかを言う。
- 背景の説明に一般常識を使うのはよいが、断定しすぎない。最新の数字は必ず素材から。

# 話し方
- 耳で聞いて分かる日本語。1行は120文字以内。記号・URL・箇条書き・表・絵文字は使わない。
- 数字は読み上げやすく（例: 1億2000万人、3.5パーセント、2026年11月）。一般的でない英字略語は日本語で言い換える。
- 2人は対等。お世辞やリスナーへの過度な称賛はしない。
- style にはその行の話し方の演出を短く（例: 落ち着いて／少し驚いて／ゆっくり強調して）。
