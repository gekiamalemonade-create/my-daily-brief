# 決めること
1. headlines: 候補から {{n_headlines}} 本。interest には、その記事が当てはまる興味分野を入れる（どれにも当たらなければ その他）。
   - 同じ興味分野は最大2本まで。「世界情勢」か「日本の経済・金融」を最低1本入れる。
   - 1本は興味リストの外からの「意外な発見」でもよい（目安 {{explore_ratio}}）。
   - 会議の開催案内・人事・調達など、リスナーにとって中身の薄いお知らせは選ばない。
2. deep_dive: 深掘り1本。重みの高い分野から、今日のニュースをきっかけに「背景・仕組み・影響・具体例」まで理解できるテーマ。
   - 直近2回の深掘りと同じ興味分野は避ける（リクエストがある場合はそれを優先）。
   - questions は3つ。政府・公的機関・企業の発表や統計などで答えを確かめられる問いにする。
   - seed_candidate_ids は、きっかけになった候補のID（なければ空）。
3. skill: 「1日1スキル」1本。学習トラックの順番どおり、前回の続きになる小さな単位（1回3分で理解できる大きさ）。
4. used_request_ids: 今回使ったリクエストのID（なければ空）。
5. editor_note: なぜこの構成にしたか（2文）。
